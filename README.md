No último ano, aprimorei meus conhecimentos em Desenvolvimento Web com HTML e CSS, lógica de programação com a linguagem C e explorei um pouco do mundo de Game Dev com auxílio da Godot.

# Principais projetos

🕹️ **Plumbum: Vingança Alienígena**. 

Projeto desenvolvido na Godot usando GDScript. Foi apresentado como projeto multidisciplinar no final do meu primeiro ano no curso de Desenvolvimento de Sistemas.

O jogo possui 3 fases que se assemelham a diferentes gêneros. 
- 1º Space Invader.
- 2º Escape Room.
- 3º Infinite Runner.

Esse projeto representou um grande passo na minha formação. Tive meu primeiro contato com desenvolvimento de jogos e com POO. Foi um grande desafio às minhas habilidades de gerenciamento e trabalho em equipe e também ao meu conhecimento técnico.
